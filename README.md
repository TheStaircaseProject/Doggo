# Doggo
An add-on for Storyline 360 that streamlines tile-based movement in SCORM-compliant learning experiences in order to make them more game-like.


## Features

- Orthogonal grid-based movement
- Top-Down 2D
- Fullscreen mode
- Easy map import template
